# Rencana implementasi awal — draf PR

**Tujuan:** menyediakan irisan awal untuk membuat dan memantau draf permintaan pembelian secara lokal sebagai dasar evaluasi antarmuka.

**Arsitektur:** React dan TypeScript untuk UI, dengan penyimpanan lokal browser sementara. Sistem operasional yang direncanakan tetap membutuhkan backend Node.js dan PostgreSQL, autentikasi, otorisasi serta audit; jangan memasukkan data nyata ke versi ini.

**Rujukan:** PRD.md, BSD.md, TDD.md, DBD.md, IPD.md.

1. Bangun dan uji validasi draf PR: judul dan cabang wajib diisi, nominal harus positif, dan nominal ditampilkan dalam rupiah. Periksa nilai kosong dan tidak valid.
2. Bangun UI daftar dan formulir draf. Pastikan draf yang valid tersimpan setelah halaman dimuat ulang; data tidak valid tidak tersimpan. Tampilkan batas penggunaan secara jelas.
3. Jalankan tes dan build, lalu periksa tampilan desktop dan seluler bila browser tersedia. Perubahan tidak menyediakan persetujuan atau pembayaran; implementasi tahap berikutnya bergantung pada aturan dan infrastruktur yang diverifikasi.
